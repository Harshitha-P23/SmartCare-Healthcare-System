🏥 SmartCare – Smart Healthcare Appointment & Patient Management System

Your Health, Our Priority ❤️

SmartCare is a modern healthcare appointment and patient management web application developed using Python Flask, SQLite, HTML, CSS, and JavaScript.

The platform helps patients connect with doctors, book appointments, manage medical information, and access healthcare services through a user-friendly interface.

🚀 Key Features

👤 Patient Management

* Patient registration and login.
* Secure password hashing.
* Patient profile management.
* Patient dashboard.

👨‍⚕️ Doctor Management

* View available doctors.
* Doctor profiles and specializations.
* Search and filter doctors.
* Doctor availability management.

📅 Appointment Management

* Online appointment booking.
* Select doctors and time slots.
* Appointment confirmation.
* Cancel and reschedule appointments.
* Appointment status tracking.

🛡️ Admin Dashboard

* Manage patients and doctors.
* Monitor appointments.
* View system statistics.
* Manage healthcare operations.

🩺 Healthcare Services

* Medical records management.
* Prescription records.
* Health information library.
* Healthcare tips.
* Notification system.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/Harshitha-P23/SmartCare-Healthcare-System.git

2. Open the project folder

cd SmartCare-Healthcare-System

3. Install dependencies

pip install flask

Install any additional packages listed in your requirements file.

4. Run the application

python app.py

5. Open in your browser

http://127.0.0.1:5000
